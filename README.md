# 🛠️ Fix My Street

**Fix My Street** is a map-based civic engagement platform designed to empower citizens to report local infrastructure and community problems—such as potholes, broken streetlights, illegal dumping, and damaged sidewalks. The platform automatically routes these reports to the relevant local authorities or tracking dashboards for rapid resolution.


---

## ✨ Features

- **📍 Map-Based Reporting:** Users can precisely drop a pin on an interactive map to pinpoint the problem's exact location.
- **📸 Media Uploads:** Attach photos of the community issue directly to the report for better context.
- **🏷️ Categorization:** Simple categorization (e.g., Roads, Lighting, Waste, Pavements) to ensure complaints go to the right department.
- **📊 Public Dashboard:** A community feed where users can see ongoing issues, view historical reports, and track resolution statuses (`Open`, `In Progress`, `Fixed`).
- **🔔 Real-Time Alerts:** Subscriptions for citizens to receive updates on issues reported in their specific neighborhood or zip code.
- **📱 Responsive UI:** Fully optimized for mobile web browsers, allowing on-the-go reporting.

---

## 🚀 Tech Stack

- **Framework:** [Flutter](https://flutter.dev/) (Cross-platform UI Toolkit)
- **Language:** [Dart](https://dart.dev/)
- **Native Integrations:** C++, Swift, and C (for high-performance map rendering and native platform channel bridges)
- **Maps API:** Open Street Map
- **Databas:** MongoDB
